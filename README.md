# Xiaomi Preset Tool

小米 / 澎湃OS 相机的预设生成器，附一份从 **64 个真实预设**反推出来的 zip 格式规范。

在线使用：https://spriteyu.github.io/xiaomi-preset-tool/

> 非官方项目，与小米公司无关。仓库内不含任何小米官方文件。详见[免责声明](#免责声明)。

---

## 这是什么

小米相机「专业模式」支持导入 `Manual_*.zip` 预设包，但小米从未公开过这个格式。网上所有教程只讲怎么导入，不讲里面是什么。

这个项目做了两件事：

1. **一份格式规范**（[docs/FORMAT.md](docs/FORMAT.md)）—— zip 里到底有哪些键、值怎么编码、为什么有些值会被相机静默忽略
2. **一个生成器**（[index.html](index.html)）—— 打开网页，五项参数拉一拉，直接下载能导入的 zip

不需要安装、不需要联网、不上传任何数据。所有文件在你本机的浏览器里生成。

## 使用方法

### 打开生成器

两种方式，任选：

- 在线版：https://spriteyu.github.io/xiaomi-preset-tool/
- 离线版：下载 `index.html`，双击用浏览器打开

### 填参数

五项风格参数，范围 −50 ~ +50：

| 参数 | 说明 |
|---|---|
| 对比度 | 负值更灰更平，正值更硬 |
| 冷暖调 | 负值偏蓝，正值偏黄 |
| 青品调 | 负值偏青，正值偏品红 |
| 饱和度 | 拉到 −50 就是黑白 |
| 锐度 | 负值柔化（胶片感），正值锐利 |

也可以点下方的「载入现成配方」，直接套用 16 组官方风格，再微调。

**不懂摄影就别展开「高级」。** 曝光补偿、白平衡、ISO、快门默认全是自动，这是所有真实预设的做法（见下文）。

### 导入到相机

1. 把生成的 zip 传到手机（微信文件传输 / 数据线 / 网盘都行）
2. 打开相机 → **专业模式**
3. 点快门右侧的 **C0** 按钮
4. 点右下角 **+** → **导入**
5. 选中 zip，回到预设列表即可使用

**不要解压 zip，不要改文件名前缀。** 相机会把最后一段中文当作预设显示名，前缀 `Manual_` 必须保留。

## 格式规范摘要

完整版见 [docs/FORMAT.md](docs/FORMAT.md)。

zip 里全是 **0 字节的空文件**，信息完全编码在文件名里：

```
p_pref_qc_camera_style_tone_key_20      # 对比度 +20
p_pref_qc_camera_style_texture_key_-15  # 锐度 -15
t / v_3 / ac                            # 三个标记文件，含义未知但必须有
```

几个必须知道的坑：

- **快门用纳秒存，且必须是 1000 的整数倍**。1/1400 换算成 714286 纳秒，不是整数微秒，相机会静默丢弃该字段并回落成自动
- **ISO 写 0 = 自动，白平衡写 1 = 自动**
- **`v_2` = 纯风格预设，`v_3` = 带专业参数**。想让预设同时含风格和 ISO/快门，必须 `Manual_` + `v_3`
- **滤镜和摄影风格（徕卡经典/生动）不在 zip 格式内**，任何预设都改不了这两项

### 一个反直觉的结论

在 64 个真实预设里（含小米官方发布的 16 组），**没有一个固定 ISO 和快门**——全部留自动。

网上流传的「ISO 500 / 1/100」式配方，在实际可用的预设里几乎不存在。固定曝光等于放弃相机自动测光，换个光照条件就废片。这个生成器默认也是全自动。

## 内置配方

- **官方 16 组**：小米社区发布的风格预设，含「高对比黑白」「大师水墨」「古典胶片」等

## 已知限制

- **只在 Xiaomi 17 Pro / HyperOS 4 上实测通过**，其他机型未验证。格式在小米 12S–17 之间据称通用，但这是第三方说法
- **滤镜、摄影风格、测光模式**均不在 zip 格式内，导入后需在相机里单独设置
- **生成器不会改你的摄影风格**，预设生效时保持相机当前设置
